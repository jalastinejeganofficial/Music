Under The Hood

Techniques & Engineering Architecture

How this Apple-grade website and the underlying full-stack application were created.

01

Euler Spring Physics & 3D Tilt

Card tilt and cursor magnetic attraction are governed by damped harmonic oscillation physics ($F = -kx - c\dot{x}$). By applying continuous rotational matrices via transform: perspective(1000px) rotateX() rotateY(), interactions achieve fluid inertia without abrupt stops.

transform: perspective(1000px) rotateX(calc(var(--rx)*1deg)) rotateY(calc(var(--ry)*1deg));
02

IntersectionObserver Scroll Hysteresis

Viewport animations use high-performance IntersectionObserver with threshold hysteresis instead of layout-thrashing scroll listeners. Elements decouple animation logic from the main layout thread, maintaining a guaranteed 60+ FPS during velocity scrolling.

new IntersectionObserver(cb, { threshold: [0.15, 0.5] });
03

Multi-Octave Sine Wave Synthesis

The background canvas generates continuous fluid acoustics using superposition of harmonic wave equations $y(x,t) = \sum A_i \sin(k_i x + \omega_i t)$. Cursor coordinates dynamically interpolate through frequency matrices, simulating viscous audio membranes.

y = Math.sin(x * freq + time) * amplitude * damping;
04

Specular Spotlight Gradients

Bento cards dynamically compute bounding boxes and project high-order radial gradients matching pointer coordinates: radial-gradient(400px circle at x y, rgba(255,255,255,0.08), transparent 80%), replicating Apple's signature specular glass reflection.

mask-image: radial-gradient(circle at var(--mouse-x) var(--mouse-y), ...);
05

FastAPI Asynchronous Scraper Backend

The backend engine is engineered on Python 3.13 and FastAPI, leveraging asynchronous non-blocking I/O (`httpx` + `asyncio`) to parse InnerTube `WEB_REMIX` headers and extract high-speed `googlevideo.com` audio stream endpoints.

async def stream(video_id: str): return await extract_stream(video_id)
06

Native Packaging (MSI, EXE, AppImage, DMG)

Packaged with WiX Toolset and PyInstaller into a clean single-window desktop executable. Custom stream redirections (`DummyStream`) prevent `.isatty()` crashes in headless mode, while GitHub Actions automates simultaneous builds for Windows, macOS, and Linux.

candle.exe Music.wxs && light.exe -out dist/Music.msi
